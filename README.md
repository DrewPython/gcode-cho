# GOST Marker

Программа для подготовки и выполнения маркировки бирок **У-136** маркером на CNC-станке с контроллером **GRBL 1.1h**. Генерирует одноштриховой G-code шрифтами «ГОСТ тип А» и «ГОСТ тип Б», показывает предпросмотр на поле 200 × 100 мм и отправляет программу на плату по последовательному порту.

## Возможности

- Два одноштриховых шрифта: **ГОСТ тип А** (узкий) и **ГОСТ тип Б** (широкий).
- Кириллица, латиница, цифры и основные знаки; предупреждение о символах, которых нет в шрифте.
- Многострочный текст, выравнивание по горизонтали и вертикали.
- Настраиваемые межбуквенный, межстрочный интервал, ширина пробела и перенос по ширине.
- Подъём и опускание маркера по оси Z, паузы, подачи, оптимизация порядка штрихов.
- Предпросмотр в масштабе: сетка 1/10 мм, контур бирки У-136, безопасная зона, холостые ходы, габариты, позиция маркера.
- Перетаскивание текста мышью, зум колесом, панорамирование.
- Экспорт G-code (`.nc`) и предпросмотра (`.svg`).
- Подключение к GRBL: список COM-портов, статус, координаты, jog, обнуление X/Y, домой, разблокировка, сброс.
- Потоковая отправка с подсчётом символов, пауза/продолжение, аварийный останов.
- Сохранение настроек в `settings.json`.
- Таблица глифов для проверки начертания.

## Шрифты

В основе шрифтов лежат эталонные файлы `gost_marker/GOST_A.TTF` и `gost_marker/GOST_B.ttf` (ГОСТ тип А и тип Б). Это не обычные контурные шрифты, а одноштриховые ГОСТ-шрифты, контуры которых «раздуты» до постоянной толщины (тип А — `d = h/14`, тип Б — `d = h/10`). Поэтому центральная линия штриха — это медиальная ось (середина) залитой фигуры.

`tools/build_centerlines.py`:

1. рендерит глиф в увеличенном разрешении (по умолчанию `--scale 2`, то есть 2 пикселя на юнит шрифта);
2. строит медиальную ось через `skimage.morphology.medial_axis`;
3. схлопывает короткие петли и перемычки, которые скелет неизбежно образует в местах пересечения нескольких штрихов;
4. сшивает разрывы по направлению самих штрихов, а не по середине;
5. сглаживает и упрощает ломаную.

В результате линии идут по центру исходных штрихов, не «съедая» половину толщины на концах и не оставляя крючков и «палок» в стыках (`Ж`, `К`, `Ф`, `8`, `М`, `ж`). Толщина исходного шрифта в G-code не переносится: маркер рисует одну линию.

Для символов, которых нет в TTF или которые в них нарисованы некорректно (`×`, `÷`, `°`, длинные тире), используется ручная реализация из `gost.py`. Ширины знаков, пробелов и межбуквенные расстояния взяты из метрик TTF.

При раскладке штрихи одного глифа с почти совпадающими концами сшиваются в один проход (допуск — около одной толщины штриха). Например, у `N` диагональ не дотягивается до верха стойки на доли толщины; короткий соединитель идёт по стойке, и буква пишется одним движением без подъёма маркера. Это уменьшает число подъёмов пера, но может дать короткое повторное проведение по уже нарисованному участку — это дешевле, чем подъём/опускание и позиционирование.

Пересобрать центральные линии после замены TTF можно командой:

```bat
python -m pip install -r requirements-dev.txt
python tools/build_centerlines.py
```

Для более гладких кривых можно увеличить разрешение: `python tools/build_centerlines.py --scale 3`. Это заметно медленнее, но даёт чуть более точную геометрию на сложных стыках.

Для обычного запуска программы дополнительные библиотеки не нужны: используется уже готовый `centerlines.py`.

## Установка

Требуется Python 3.10+ (проверено на Python 3.12).

```bat
"C:\Users\Administrator\AppData\Local\Programs\Python\Python312\python.exe" -m pip install -r requirements.txt
```

`pyserial` нужен для связи со станком, `openpyxl` установлен как задел для будущей загрузки списка из Excel. Без `pyserial` программа запускается, но подключение к станку недоступно.

## Запуск

Двойной клик по `run.bat` или:

```bat
python app.py
```

Файл `run.bat` использует путь к Python 3.12; при другой установке замените переменную `PY` или запустите `python app.py` вручную.

## Быстрый порядок работы

1. Введите текст на вкладке **«Текст»** (Enter — новая строка).
2. Выберите шрифт и размер. Размер — высота прописных букв в мм.
3. Проверьте положение. Кнопка **«Центр бирки»** ставит текст в центр треугольника, **«Вписать в бирку»** подбирает максимальный размер, при котором габарит помещается в безопасную зону.
4. Нажмите **«Обновить»** — предпросмотр и статистика пересчитаются.
5. На вкладке **«Станок»** выберите COM-порт и подключитесь.
6. Вручную установите бирку в начало координат станка (X0 Y0 — левый нижний угол бирки).
7. Подведите маркер к бумаге, настройте `Z опущено` / `Z поднято` и проверьте на черновике.
8. Нажмите **«Печать на станке»**. При выходе текста за поле или безопасную зону программа спросит подтверждение.

## Настройка оси Z

Маркер закреплён на оси Z. В программе:

- `Z поднято` — маркер не касается бумаги (по умолчанию 5 мм);
- `Z опущено` — маркер касается бумаги без сильного нажима (по умолчанию 0 мм);
- `Подача Z` — скорость подхода к бумаге.

Значения подбираются экспериментально. Начните с поднятого маркера, опустите его вручную jog-кнопками, добейтесь лёгкого касания и запишите координату. Слишком большой нажим приводит к «кляксам» и быстрому высыханию маркера.

## Бирка У-136

Бирка трактуется как равносторонний треугольник, основание которого лежит на оси X, вершина направлена вверх, начало координат — левый нижний угол. По умолчанию сторона **62 мм**; у разных производителей встречается около 55 мм, поэтому сторону и отступ безопасной зоны можно изменить.

Два продолговатых отверстия на предпросмотре показаны условно — они нужны только для наглядности. Реальное положение бирки на столе задаётся вручную.

Внимание: если бирка лежит иначе (перевёрнута, повёрнута), текст тоже нужно расположить соответственно либо повернуть бирку на столе.

## G-code и GRBL

Генератор выдаёт:

```gcode
G21
G90
G94
G17
G0 Z5
...
G1 Z0 F300
G4 P0.15
G1 F1200
G1 X... Y...
G0 Z5
...
M2
```

Особенности:

- единицы — миллиметры, координаты абсолютные;
- холостые ходы по умолчанию через `G0`;
- перед рисованием задаётся подача `G1 F...`;
- штрихи одного глифа с близкими концами сшиваются в один проход;
- порядок оставшихся штрихов оптимизируется жадным обходом ближайшего штриха;
- после каждого несшитого штриха маркер поднимается;
- в конце — подъём и парковка (можно отключить).

Отправка идёт потоково с подсчётом символов (RX-буфер 120 байт) и подтверждениями `ok`. Кнопка **«Пауза»** использует feed hold (`!`), продолжение — `~`. **«Стоп»** отправляет feed hold и soft reset (Ctrl-X). При аварийной ситуации используйте физическую кнопку питания/сброса станка.

## Настройки

Кнопка **«Сохранить настройки»** записывает `settings.json` рядом с программой: текст, шрифт, координаты, параметры бирки, станка и предпросмотра. Настройки загружаются при следующем запуске. Геометрия окна также сохраняется.

## Расширение

- **Excel**: `openpyxl` уже в зависимостях. Загрузку списка бирок удобно добавить отдельным модулем `batch.py`, который формирует набор текстов и координат, а затем по очереди вызывает `layout_text()` и `generate_gcode()`.
- **SQLite**: стандартный `sqlite3`; таблица заданий может хранить текст, шрифт, размер, координаты и статус выполнения.
- **Шрифты**: глифы описаны в `fonts/gost.py` в нормированных координатах (высота прописных = 1.0, базовая линия = 0). Новый знак добавляется как `Glyph(width, strokes)`; толщина линии в G-code не используется.

## Ограничения

- Центральные линии строятся по середине исходных штрихов. На очень сложных стыках (например, `ж` типа Б) середина зоны перекрытия штрихов может давать короткий почти горизонтальный участок — это геометрически честная середина, а не сбой.
- При сшивке штрихов внутри глифа возможен короткий повторный проход по уже нарисованному участку (доли миллиметра). Это плата за отказ от подъёма пера; на скорость обычно выгоднее.
- Для незнакомых символов выводится предупреждение; они пропускаются.
- Перед первой печатью обязательно проверьте траекторию на черновике и аварийный останов.
- Программа не управляет включением шпинделя/лазера: предполагается маркер, закреплённый на оси Z.
